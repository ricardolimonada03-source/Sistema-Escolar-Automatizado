# Sistema Escolar Automatizado

Sistema web diseñado para automatizar procesos administrativos escolares como:

- Gestión de alumnos
- Control de asistencias
- Registro de calificaciones
- Reportes académicos
- Tutorías

## Tecnologías planeadas

- Python
- FastAPI o Django
- PostgreSQL
- HTML/CSS/JavaScript
- GitHub

## Objetivo

Reducir el trabajo manual en Excel y centralizar la información académica en una plataforma web moderna.
